# 10.1 P Critic synthesis round 1

Status: addressed
Critic report: `.jwc/plans/planphase/2026-07-02-1325-8f6b/stage-10-critic.md`
Verdict: ITERATE

## Findings

### C10-01 — compact helper contradicted integer test expectations

Decision: accept.

The draft proposed a decimal/tenths helper for `formatNumber()` integer bands while the acceptance tests intentionally expect integer clamp outputs like `999K` and `999M`. Applied literally, the helper would produce `999.5K`/`999.9K`.

Plan change:

- Cluster B now specifies `compactIntegerUnit(n, unit)` for current integer K/M/B bands only.
- Existing `trim1()` decimal bands remain unchanged.
- Byte formatting keeps the separate tenths clamp because byte outputs intentionally include one decimal place.

### C10-02 — settings timeout helper lacked the actual wiring target

Decision: accept.

The draft added `applyConfiguredSearchTimeout(settings)` but did not explicitly replace the current `WebSearchTool.execute()` callsite that reads `settings.get("web_search.timeout")` and calls `setSearchHardTimeoutMs(...)` directly. That left execution ambiguous and could let schema defaults keep overriding class defaults.

Plan change:

- Cluster D now explicitly requires replacing the `WebSearchTool.execute()` settings timeout wiring with `applyConfiguredSearchTimeout(this.#session.settings)` or equivalent source-aware logic.
- Acceptance now requires testing override semantics through the actual `WebSearchTool.execute()` settings path.

### C10-03 — Kagi missing from API-class timeout rollout

Decision: accept.

Kagi's shared helper in `packages/coding-agent/src/web/kagi.ts` uses `withHardTimeout(options.signal)` and is an API-class search call. The draft's provider list omitted it while the acceptance criteria implied all API-class providers.

Plan change:

- Cluster D API-class provider list now includes `packages/coding-agent/src/web/kagi.ts`.
- Acceptance explicitly names Kagi's helper as part of API-class timeout coverage.

## Result

The plan now aligns helper mechanics with test expectations, names the timeout settings owner callsite, and includes the missing API provider. Re-run Critic against the patched plan and this synthesis.
