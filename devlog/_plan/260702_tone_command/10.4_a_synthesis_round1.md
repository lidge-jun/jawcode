## 메인 세션 독립 검증 (read-only, 소스 직접 확인)

- **ARCH-A1 사실 확인**: `settings-schema.ts:3089-3092` enum 분기는 `V[number]`만 반환 — `set("identity.tone", undefined)`는 tsgo 컴파일 에러. string 분기는 `string | undefined`(3086)라 toneCustom은 문제 없음. **확정.**
- **widen 부작용 확인**: `get("tool.renderMode")` 호출부는 리포 전체에서 1곳(`modes/controllers/event-controller.ts:173`)이고 이미 `?? fallback` 사용 — default-undefined enum 분기를 `V[number] | undefined`로 넓혀도 기존 호출부 무파손. 오히려 기존 type lie(런타임 undefined 가능인데 타입은 non-nullable) 교정.
- **ARCH-A2 경로 확인**: `settings.ts` `set()`→`setByPath(#global, seg, undefined)`→`#saveNow()`가 재독 YAML에 undefined를 setByPath(832) 후 `YAML.stringify`(837, `import { YAML } from "bun"` — settings.ts:27). Bun YAML의 undefined 처리는 소스만으로 미확증 → 라운드트립 테스트로 고정하는 게 맞음. **수용.**
- **ARCH-A3/PLANNER-A6 사실 확인**: `builtin-registry.ts:1916-1926` TUI 디스패처는 `handleTui` 부재 시 `handle(parsed, adaptTuiSlashRuntime(ctx))`로 위임, `adaptTuiSlashRuntime`은 1936-1957. **확정.**
- **ARCH-A4 사실 확인**: `/effort` handle은 args를 `trim().toLowerCase()` 정규화 — 복붙 시 custom 문안 파괴. **확정.**
