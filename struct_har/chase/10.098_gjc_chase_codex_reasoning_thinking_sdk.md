## Chase Scope

This card tracks one reasoning contract across model metadata, SDK control, provider transport, and session queues. Upstream exposes each model's thinking capability through SDK queries, preserves explicit thinking selection durably, drops unmarked reasoning at gateway boundaries, classifies `invalid_prompt` as deterministic history corruption, allows one bounded repair, and fences reasoning-summary frames by turn ownership.

The security boundary matters more than UI parity. Internal reasoning must not be promoted into user-visible assistant reasoning without provenance, and stale queue frames must not cross turn boundaries. Retry repair must terminate predictably instead of looping on a history error that cannot succeed unchanged.
