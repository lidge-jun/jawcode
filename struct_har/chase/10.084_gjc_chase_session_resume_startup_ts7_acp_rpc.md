## Risk Notes

Resume confirmation must not mutate a session merely by browsing it, and headless cancellation must return stable nonzero codes. Startup fixes need compiled-artifact tests; source-only tests cannot prove bundling. ACP/RPC changes alter public wire behavior, so fixtures should test complete events and configured permission modes. Memory optimization must not discard resumable blobs or transcript fidelity.
