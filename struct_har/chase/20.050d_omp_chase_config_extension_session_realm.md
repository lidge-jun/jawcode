## Why This Sub-Card

This slice follows state from configuration discovery and profile inheritance into extension UI registration, LSP workspace resolution, memory/session reconstruction, and same-realm JavaScript lifetime. The shared seam is preservation of caller-selected state across clone, reload, context rebuild, and runtime reconfiguration boundaries; none of the OMP module shapes is itself a JWC port directive.

JWC owner signals are `packages/coding-agent/src/config/{settings,config-file,keybindings}.ts`, `packages/coding-agent/src/extensibility/extensions/`, `packages/coding-agent/src/modes/interactive-mode.ts`, `packages/coding-agent/src/lsp/`, `packages/coding-agent/src/session/`, and `packages/coding-agent/src/eval/js/{shared/runtime,worker-core}.ts`, with browser propagation in `packages/coding-agent/src/tools/browser/tab-worker.ts`. OMP-only mnemopi and snapcompact concepts require an equivalent JWC owner to be identified before any adaptation.
