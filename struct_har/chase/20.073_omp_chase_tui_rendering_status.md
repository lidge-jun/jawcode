## Chase Scope

This card tracks OMP's post-17.0.1 TUI correctness wave. It spans alt-screen resize borrowing, status-line overflow and continuation rows, explicit appearance refresh, stdin-listener ownership during extension loading, Ask space handling, usage and model-role labels, GFM autolink boundaries, and a concentrated skill-autocomplete series that preserves drafts while tightening stale-prefix and slash anchoring.

The image sequence needs special treatment. `980ba0be8` implements inline-image preservation in scrollback, but `8876eef88` later reverts that merge. The surviving `a140f2199` invariant is narrower: retain transcript context around image overlays. The reverted implementation is evidence, not current OMP behavior to copy blindly.

JWC's TUI has a stronger independent canonical-scrollback model built around `commitLines()`, `replayTranscript()`, and viewport repaint. It also already has image, markdown, editor/autocomplete, status-line, and Ask owner surfaces. Comparison must therefore be test-first and invariant-based; replacing JWC's viewport model is out of scope.

All 21 non-overlapping commits in the TUI/status/scrollback/image/Ask/GFM/autolink/draft cluster are retained. Warp event bridging belongs to 20.071, while plan-review overlay ordering belongs to 20.072.

- [ ] Preserve JWC canonical scrollback and resize invariants.
- [ ] Treat the reverted OMP inline-image patch as reference-only until its failure mode is understood.
- [ ] Keep status information single-row or predictably priority-dropped at narrow widths.
- [ ] Preserve host stdin listeners across tool/extension loading.
- [ ] Prevent Space and Enter from prematurely submitting Ask or skill drafts.
- [ ] Bound markdown autolinks and slash completion to valid token boundaries.
