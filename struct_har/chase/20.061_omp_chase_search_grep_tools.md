# 20.061 — omp chase: search, grep, and tool-surface consolidation

## Chase Scope

This card spans native grep correctness and the model-visible search/read contract. OMP adds PCRE2 and traversal features, normalizes regex modes, reads stable snapshots, controls allocation and buffer sizing, and distinguishes empty results from timeouts or truncated windows. It also changes selector grammar, file completion, raw reads, internal-URL write permissions, and xAI web-search transport propagation.

JWC intentionally exposes `search` rather than OMP's `grep`. Its owner fetches a bounded native result set, groups by file, applies per-file caps, and emits a round-robin file window. That contract must not be replaced by OMP's ranged-grep API. Likewise JWC's embedded read selectors and immutable internal-URL handlers are existing product semantics. The `xd://` consolidation commit is architectural reference only unless JWC separately chooses that device model.

All 38 D11 commits are retained. The broad tool-surface commit is represented by its principal owners rather than listing every touched file.

| xAI search transport | **exists/unclear** | model registry preserves transport overrides and xAI has a native search provider; the provider does not visibly consume the configured model transport in the targeted search. |
