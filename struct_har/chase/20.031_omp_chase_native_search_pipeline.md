## Why This Is A Gap

OMP introduced a much larger native traversal/search layer after v16.2.9: `pi-walker`, native fast directory traversal, two-pass search for large files, cancellation-aware grep/fd walks, native crash/panic hardening, and CJK-capable font assets. JWC has native helpers too, but these changes are architectural and should be treated as reference material before any import.
