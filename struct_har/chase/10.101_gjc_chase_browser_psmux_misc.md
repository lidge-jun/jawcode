## Chase Scope

This card collects long-run recovery work across browser tabs and profiles, stealth/geo configuration, bounded browser teardown, psmux/tmux compatibility ownership, managed assistant message shells, and cooperative mid-run context maintenance. The shared invariant is that a registry or coordinator may recover a dead resource only when it can prove the resource and its artifacts still belong to the same profile, turn, and session.

JWC has browser launch and tab-supervisor owners plus JWC-named psmux detection, launch-tmux, and team runtime code. It does not currently expose the upstream `profile-reuse.ts`, `profile-warmup.ts`, or `tmux-owner-isolation.ts` paths. Browser and multiplexer changes therefore need behavior-level adaptation; upstream `gjc-runtime` paths and environment names must never be copied verbatim.
