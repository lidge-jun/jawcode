## Chase Scope

This card tracks control-token neutralization and untrusted-content framing across fetched data, runtime context, file mentions, replay history, remote compaction, and Responses request construction. It also covers explicit `invalid_prompt` handling so blocked requests terminate through a bounded circuit breaker instead of amplifying retries.

Reasoning transport is part of the same boundary. Raw reasoning must not escape through directed frames, summaries, Telegram replay, or provider translation, while marked summaries remain available through the intended operator contract. JWC must verify these boundaries end to end across AI providers, agent compaction, prompt assembly, and notification delivery.
