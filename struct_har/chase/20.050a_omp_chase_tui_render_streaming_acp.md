## Why This Sub-Card

This slice covers the runtime seam from terminal input and capability reports through frame repaint,
scrollback row commitment, streaming tool presentation, read previews, and ACP final-text delivery. In
JWC, the principal owners are `packages/tui/src/tui.ts`, `terminal.ts`, `autocomplete.ts`, and
`insert-history.ts`, together with `packages/coding-agent/src/modes/components/tool-execution.ts`,
`read-tool-group.ts`, `modes/controllers/input-controller.ts`, and `modes/acp/`.

JWC does not have OMP's `latex-block.ts`, `latex-to-unicode.ts`, or `transcript-container.ts`, while its
current `tui.ts` has a distinct commit/scrollback/replay design. The anchors therefore preserve repaint,
cancellation, resize, completion, preview, and final-flush invariants for owner-level comparison; they do
not imply that OMP's component boundaries or rendering engine fit JWC.

## Reference Decisions

| commit group | decision | rationale |
| --- | --- | --- |
| Math grid (`7cbe9fc0a`) | **reference** | The grid-layout behavior is useful evidence for complex math rendering, but JWC has no matching LaTeX owner files. Any future math surface must first establish a JWC product owner and compatibility with its current frame model. |
| Repaint and row commitment (`6db9ab606`, `0dbb59a14`, `cde9ee750`, `4a20b51ca`) | **reference/adapt by invariant** | Flicker-free destructive paint, stale-cell cleanup, first-partial repaint, and exactly-once row emission are portable correctness properties. JWC's `viewportRepaint`, `commitLines`, `replayTranscript`, and live tool owners require an independent fit review rather than OMP component transplantation. |
| Escape ordering (`894cf489f`) | **reference/compare** | First-Escape cancellation is user-visible, but JWC already prioritizes optimistic submission, bash/eval, panels, queued steers, and explicit user interrupts. Compare ordering semantics against that richer hierarchy. |
| Terminal reports and appearance (`2aee4bd3f`, `e07909fda`) | **reference/adapt by invariant** | Robust DEC parsing and replay to late subscribers belong at JWC's `terminal.ts` boundary. Appearance state exists; the search did not establish equivalent DEC 2048 colon-subparameter coverage. |
| Autocomplete (`80b186cd8`, `58336f588`) | **reference/compare** | Whitespace after no-arg commands and slash-Tab non-reopening are editor contracts. Evaluate them against JWC's current skill/slash/path ranking and action completion tests. |
| Read preview (`ba91877b6`) | **reference/compare** | Explicit selectors should remain visible in previews, but JWC's read tool supports embedded, compound, multi-range, archive, URL, and internal-resource selectors. Preview parity must preserve that grammar. |
| ACP final text (`7c560c715`) | **reference/verify equivalence** | Final assistant content must be emitted exactly once even when no deltas arrive. JWC already has mapper tests for final text with and without deltas; the remaining question is race equivalence at its ACP agent boundary. |
