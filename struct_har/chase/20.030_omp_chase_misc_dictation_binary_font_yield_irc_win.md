## Why This Is A Gap

OMP v16.2.5→v16.2.9 shipped several independent quality/robustness fixes that don't cluster with the larger themes: automatic dictation submission triggers, binary file detection to prevent encoding corruption, dynamic font rendering with CJK + unicode support, per-label incremental yield validation (prevents fatal schema_violation), IRC pending-aside inbox/consume handling, Windows worker fallback + extension path fixes, a Bun CPU-profiler guard for `v8.setFlagsFromString`, and stream-timeout forwarding. Each is an isolated reference for the matching JWC surface.

Behavioral surface:
1. Automatic dictation submission triggers.
2. Binary file detection to prevent encoding corruption.
3. Dynamic font rendering with CJK + unicode support.
4. Per-label incremental yield validation (prevent fatal schema_violation).
5. IRC: surface pending asides in inbox; consume peeked pending asides (avoid double-inject).
6. Windows: strip worker fallback executable; preserve extension paths.
7. Bun CPU profiler: guard `v8.setFlagsFromString`. Stream-timeout forwarding.
