## Chase Scope

This cluster protects differences hidden behind nominally compatible transports. Vertex must not inherit unsupported Anthropic beta/effort behavior, custom Anthropic endpoints need provenance-aware eager streaming, Google and CCA require bounded JSON Schema adaptation, reasoning models must omit unsupported sampling fields, and Copilot vision must preserve both confirmation and denial.

The residual transport set adds Bedrock stringify guards, batched decoding, Responses terminal details, null assistant content, terminal content blocks, proxy-aware secure WebSockets, Codex summary ordering, pre-response watchdog retry, Cursor TLS handling, and removal of legacy Google Interactions. These are independent correctness seams and should not be closed as one broad provider rewrite.
