### Split residual for tmux/cmux owner

The tmux/cmux cluster is not falsely accepted as part of WP5 because its implementation files are outside this work
package's ownership. Investigation found concrete residuals:

- `jwc-runtime/launch-tmux.ts` still issues `resize-window` for native tmux instead of preserving `window-size latest`.
- Initial sizing does not account for tmux status-line rows.
- A nonzero attach with empty stderr still falls through to session cleanup rather than probing and preserving a live
  tmux session.
- JWC has no `utils/cmux-workspace.ts` equivalent for guarded workspace auto-rename.
- Coordinator delivery already sends submit keys, but multiline delivery should be reconciled with the upstream
  `f831abf9` buffer/paste behavior by the coordinator owner.

Those items should remain a separate tmux/coordinator/cmux work package with ownership of
`jwc-runtime/launch-tmux.ts`, `coordinator-mcp/server.ts`, and a deliberate decision on cmux support.
