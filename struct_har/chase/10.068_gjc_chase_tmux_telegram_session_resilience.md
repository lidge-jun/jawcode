Notes:

- JWC now detects native Windows `psmux` attach refusal containing `(os error 10061)`, waits briefly, and retries attach when the session still exists.

- New managed tmux sessions now receive the caller terminal dimensions at creation time and reassert them before attach after profile/title setup.
