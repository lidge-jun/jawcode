## Chase Scope

OMP hardens the complete multi-account OAuth lifecycle. Invalid or quota-limited rows rotate, provider refreshes serialize, refresh races retain the intended row, stale session stickies clear, and stored schemas reject malformed state conservatively. A long follow-up series makes organization qualify rather than replace member identity across storage, broker routing, usage caches, status, and logout.

The cluster also covers login paste-code handling, Perplexity bearer isolation, auth-gateway diagnostics, nested broker configuration, web-search auth reuse, subagent session identity, and MCP dynamic-client-registration fallback. JWC has matching owner surfaces, but file existence cannot establish that every identity consumer applies one rule.
