## Adoption Guidance

Reject any direct copy of OMP's shared block model unless JWC first proves an equivalent block
scope exists. Adapt only the invariant: a healthy live usage read should clear stale local blocks
for the same credential scope. Likewise, account rotation should happen before model fallback only
when the failed credential can be identified and suppressed without leaking provider state across
sessions.
