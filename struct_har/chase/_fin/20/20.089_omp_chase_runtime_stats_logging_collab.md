## Implementation Evidence

- `48a473d` — retention gated behind an explicit spawn-time request; `wait({ stderr: "full" })` without it rejects rather than silently returning a truncated tail; `exec` retains via an internal `spawnInternal` instead of forwarding `stderr` into public `spawn` (which would tee a stream it never consumes).
- `73415e9` — adds `stderr: "stream"` (expose without retaining) and migrates RPC, MCP stdio and SSH, the three long-lived callers that consume the stream themselves and never call `wait({ stderr: "full" })`. LSP was already retention-free.
- `8cf381b` — removes `stderr: "full"` from `youtube.ts`, `fetch.ts` and `tools-manager.ts`, which requested full capture and read only stdout/exitCode. `exec/exec.ts` keeps it: it returns `result.stderr`.
