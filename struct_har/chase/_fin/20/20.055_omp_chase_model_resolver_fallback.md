## Chase Scope

OMP hardens model fallback from parsing through runtime recovery. Wildcards and thinking suffixes must resolve without corrupting model identity; hard provider failures and exhausted retry budgets may advance a configured chain; and automatic role assignment must not retain stale thinking. Switching from a vision model to a text-only model strips incompatible image blocks from provider input while preserving transcript meaning.

OMP also adds persistent performance samples, migration/backfill, model-hub visibility, interactive chain editing, GPT-5.6 Codex search support, YAML model configuration, and removal of the legacy `pi/` role alias. JWC already has substantial fallback and role logic, so this card is an equivalence audit plus explicit product decisions for persistence and UI.
