### Why a typed discriminator rather than an exit code

Upstream folded launch failure into a non-zero result. That is unsafe here, and the audit proved it: **real git can exit 127** (`git -c alias.probe='!exit 127' probe`). Collapsing would have made `/review` announce "No uncommitted changes found", `branch.default` silently keep an assumed `main`, and `patch.canApply` report a conflict — all confident answers about a repository nobody could inspect.
