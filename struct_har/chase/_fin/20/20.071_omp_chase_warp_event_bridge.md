## Chase Scope

This card tracks OMP's Warp-native session event protocol. The initial pair adds an OSC emitter and bridges TUI lifecycle events. The follow-up wave binds events to active prompts, refreshes session identity across branches, emits exact permission payloads, distinguishes successful and failed stops, and suppresses duplicate legacy notifications while the Warp protocol owns completion.

The portable contract is terminal-session lifecycle correctness, not unconditional Warp integration. JWC already exposes generic `session_branch` and `permission_request` events through its hook and bridge layers, but it has no `warp-events.ts` owner. Any adoption must keep terminal-specific framing behind an adapter and preserve JWC's existing bridge/event contracts.

All 17 commit messages matching the Warp, OSC, event-bridge, emitter, `session_branch`, or `permission_request` cluster are retained below. Documentation and style commits remain evidence for ownership and release intent.

- [ ] Define the canonical prompt/session identity carried by terminal events.
- [ ] Distinguish terminal stop, stop failure, and stop-with-continuation states.
- [ ] Prevent duplicate completion notifications when a native protocol owns them.
- [ ] Preserve exact permission request framing through tmux and direct terminals.
- [ ] Keep Warp-specific OSC transport optional and isolated from generic hooks.
