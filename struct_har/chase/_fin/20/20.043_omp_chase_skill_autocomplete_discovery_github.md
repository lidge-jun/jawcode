## Adoption Guidance

Prefer a JWC-native autocomplete audit before patching. Mid-prompt completion should be token-scoped
so stale suggestions do not submit against a changed token. Description matches should preserve the
selected skill identity instead of collapsing back to the visible label. GitHub `#number`
completion should be live only when repo identity and auth state are known; otherwise it should
degrade to inert text rather than blocking prompt entry.
