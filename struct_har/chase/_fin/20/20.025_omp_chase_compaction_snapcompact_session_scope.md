## Why This Is A Gap

OMP v16.2.5→v16.2.9 tightened compaction memory safety and scoped compaction to the active session branch: snapcompact frames are capped (payloads, unknown-window, newest-kept), snapshot caps share an aggregate budget across per-file results / edit-tool oldText-newText / hashline multi-section, pruned-snapshot markers are preserved through single-path aggregation, auto-compaction dead-ends recover via shake elisions, compaction elision is scoped to the active branch (avoiding ctrl-c rewrites for compacted sessions), and mid-run compaction matches persisted messages by key identity. JWC's compaction/resident-memory work (10.040 _fin) can use these as bounds/scoping references.

Behavioral surface:
1. snapcompact frame caps: payloads, unknown-window cap, keep-newest.
2. Shared aggregate snapshot budget across perFileResults / edit oldText-newText / hashline sections.
3. Preserve pruned-snapshot marker through single-path aggregation.
4. Recover from auto-compaction dead-ends via shake elisions.
5. Scope compaction elision to the active branch; avoid ctrl-c rewrites for compacted sessions.
6. Match persisted messages by key identity during mid-run compaction.

OMP's 6 behavioral surfaces (11 commits) triaged against JWC: only the bounded edit-tool snapshot has a real JWC surface; the rest target OMP's `packages/snapcompact` package and `session-loader.ts` supersede-elision architecture that JWC does not have.

JWC slice (commit `314b7a1`): new `packages/coding-agent/src/edit/snapshot-details.ts` — `MAX_EDIT_SNAPSHOT_TEXT_CHARS=32768`, `pruneOversizedEditSnapshots` (drops oversized single snapshots) + `capPerFileSnapshots` (shared left-to-right aggregate budget; over-budget per-file entries stamped `snapshotsPruned: true`). Wrapped at 4 persisted apply sites: `replace.ts`, `patch.ts`, `edit/index.ts` (`aggregateApplyPatchResults` + `executeSinglePathEntries`). Additive `snapshotsPruned?: boolean` field on `EditToolPerFileResult`. Small edits (≤32KB combined) pass through byte-identical; oversized edits keep `diff`/`path`/`firstChangedLine`/`op`/`move`/`diagnostics`/`meta` and degrade ACP diff to text-only.
