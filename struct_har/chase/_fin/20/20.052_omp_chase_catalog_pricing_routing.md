## Chase Scope

This cluster records that a model name is not a complete runtime contract. Kimi K2.7-Code limits and idle floors vary by provider, Copilot MAI Code requires Responses routing and stale-route invalidation, Z.ai GLM pricing/effort comes from specific catalog keys, and OpenCode discovery and caches need provider-aware precedence.

JWC has no OMP-style `packages/catalog`; its source owners are `packages/ai/src/provider-models/`, `model-manager.ts`, catalog generation scripts, provider transports, and generated `models.json`. Any adaptation must change descriptors/resolvers and regenerate output. Usage reconciliation in OpenRouter remains a transport concern and must not be mistaken for metadata parity.
