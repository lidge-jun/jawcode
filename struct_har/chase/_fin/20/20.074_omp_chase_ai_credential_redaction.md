## Chase Scope

This model-related card tracks two AI transport safety boundaries. The credential series redacts secrets from outbound messages, system-prompt instructions, and GitLab Duo goal transcripts; removes stale thinking signatures after mutation; scopes Kimi search credentials; and makes recursive object redaction safe for `BigInt`. The response series retries a full transcript when a stateful OpenAI Responses prompt is blocked, then hardens stream-markup healing so indented fences, fence-only closes, and literal think tags inside code remain visible.

Redaction must happen before provider serialization without silently corrupting tool payloads, signed thinking blocks, or replay identity. Retry must be bounded and must not duplicate side effects. Markdown healing must distinguish protocol markup from literal code. These are P1 boundaries because a mistake can leak secrets, crash request construction, or alter model-visible/user-visible content.

JWC has the same high-level AI owners (`transform-messages.ts`, OpenAI Responses providers, Cursor/Kimi/GitLab surfaces), but the targeted sweep found no OMP-equivalent `redactSensitiveInObject` test suite or `dialect/thinking.ts` markup-healing owner. Existing thinking-signature sanitation is adjacent behavior, not proof of credential redaction.

All 10 commits matching the requested credential-redaction, blocked-retry, BigInt, markdown-fence, think-tag, and Kimi credential-scope cluster are retained. AI commits about usage limits, Kimi output limits, or custom base URLs are excluded because they do not belong to this safety unit; Cursor protocol completion belongs to 20.072.
