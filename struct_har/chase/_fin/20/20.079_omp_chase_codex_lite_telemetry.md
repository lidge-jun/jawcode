## Chase Scope

This is a model-related partial cluster. It combines four small but connected provider boundaries: Responses Lite rewrites must not leave an invalid hosted-tool choice, explicit `none`/`required` constraints must survive that rewrite, image generation must resolve provider intent per request without exposing an unsafe default tool, and local llama.cpp Qwen models must receive a real wire-level thinking-disable dialect.

The same wave adds OTLP logs and metrics beside traces. JWC currently has OpenTelemetry trace dependencies and a centralized TUI-safe logger, but no OMP-style `telemetry-export.ts`. Telemetry therefore remains a directional comparison rather than a direct port. Codex Lite shaping is also only partial because JWC's current Codex transformer has no `responsesLite` branch.

- [ ] Keep `generate_image` opt-in and verify provider selection, Codex credentials, and invalid-key fallback per request.
