## Chase Scope

This card covers discovery state from a plugin or Codex configuration file to the spawned stdio process, runtime skill registry, slash commands, system prompt, local image arguments, and tool rendering. Relative `command` and `cwd` values must resolve from the configuration or plugin root that declared them, not from whichever process directory happens to launch the session.

JWC has its own capability-based discovery and `runtime-mcp/` architecture. Its Codex importer currently reads project `.codex/config.toml` but the inspected extraction path copies `command` and `args` without config-directory rooting and does not forward `cwd`. JWC also has an in-flight `runtime-skill-discovery.ts` implementation. Any adaptation must preserve those owners and reconcile the current dirty changes rather than import OMP's `src/mcp/` or `xd://` cache design.

All 22 D12 commits are retained. LSP and walker items are separable residuals, not reasons to widen the MCP implementation unit.
