## Chase Scope

This card tracks Grok 4.5 catalog support, GPT-5.6 Codex role presets, benchmark evidence, and coordinator-authoritative `mpreset` selection. Upstream resolves a preset before session spawn, rejects unknown profiles, records the selected profile in session state, and fails closed when reuse conflicts with an existing session profile.

JWC already carries current model metadata and profile tiers. The key gap is authority: a CLI-visible profile is not sufficient if a coordinator-started session can omit it or reuse a session under a conflicting profile. Benchmark receipts are also needed so role/effort choices remain auditable rather than becoming unexplained constants.

## Worktree Verification

JWC already contains Grok 4.5 entries in the generated model catalog, GPT-5.6 Luna/Sol/Terra descriptors, and `codex-standard`/`codex-pro` role mappings in `model-profiles.ts`. CLI `--mpreset`, persistent default activation, catalog tests, and user documentation are also present.

The coordinator `start_session` schema only accepts `cwd`, `prompt`, and `allow_mutation`; the coordinator tree contains no `mpreset` or model-preset resolver. Consequently, spawn-time rejection, state persistence, and reuse-conflict behavior are not implemented on that path. JWC has general benchmark tooling, but no focused `gpt-5.6-codex-preset-benchmark.md` equivalent was found to explain the current role/effort constants. Static catalog/profile support is ahead; coordinator authority and benchmark receipt remain the chase.
