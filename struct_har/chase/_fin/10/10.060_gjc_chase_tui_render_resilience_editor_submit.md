## Why This Is A Gap

GJC v0.7.8 made the TUI render loop fault-tolerant and improved the composer/status-line UX in four commits: per-component render failures are now isolated so a single throw cannot crash the whole app; Ctrl+Enter reliably submits the composer; the status-line custom editor UX is improved; and a status-line usage display mode is added. JWC shares most of these paths (`packages/tui/`, `modes/components/status-line*`), so this is a behavior-parity reconcile rather than a rename.

Behavioral surface:
1. Per-component render isolation — one component throw cannot crash the TUI app.
2. Ctrl+Enter composer submission fixed (keybinding + editor handling).
3. Status-line custom editor UX improvements (settings-selector + settings-list).
4. Status-line usage display mode (new segment/display option).
