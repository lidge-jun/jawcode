TUI and diagnostic fixes are import/adapt candidates; Telegram and tmux require JWC naming and lifecycle adaptation.

## Risk Notes

Escape handling must stay local only while inline ask input owns the key; global cancellation must still work otherwise. IME changes touch `packages/tui/src/tui.ts`, so preserve JWC's existing scroll/repaint contract and test iTerm behavior manually. Telegram cleanup must never delete a topic merely because a rename failed. Tmux title tracking must distinguish a user rename from process death. MCP disclosure must not print credentials or secret environment values.
