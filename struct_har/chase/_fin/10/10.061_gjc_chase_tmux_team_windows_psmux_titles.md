## Completion Evidence — 260701

Implemented JWC-adapted tmux/psmux reliability:

- `packages/coding-agent/src/jwc-runtime/tmux-title.ts`
  - builds `JWC-<project>-<branch>` tmux window labels with visible-width truncation, dot-directory handling, colon sanitization, and `#` escaping for terminal titles.
- `packages/coding-agent/src/jwc-runtime/psmux-detect.ts`
  - resolves native Windows psmux candidates (`psmux`, `pmux`, `tmux`);
  - supports JWC psmux env aliases before legacy `GJC_*` aliases;
  - treats explicit `psmux`/`pmux` command names as psmux without relying on a live probe.
- `packages/coding-agent/src/jwc-runtime/tmux-inner-command.ts`
  - strips the outer `--tmux` from the inner launch command;
  - emits BOM-less PowerShell `-EncodedCommand` on Windows with `pwsh` / `powershell` / `powershell.exe` fallback support.
- `packages/coding-agent/src/jwc-runtime/launch-tmux.ts`
  - removes the native Windows early return when psmux/tmux is available;
  - renames managed windows and sets root terminal titles best-effort for native tmux;
  - captures stderr for launch diagnostics using `jwc --tmux` wording;
  - probes session registration with bounded backoff instead of duplicating same-name `new-session` on psmux races;
  - preserves SIGHUP/EIO attach disconnects but kills newly created sessions on ordinary attach failure.
- `packages/coding-agent/src/jwc-runtime/tmux-common.ts` and `tmux-sessions.ts`
  - share psmux-aware exact-target helpers so native tmux keeps `=NAME` / `=NAME:` while psmux uses bare names.
- `packages/coding-agent/src/jwc-runtime/team-runtime.ts`
  - delegates tmux command resolution to the shared helper;
  - normalizes worker prompts to one line before quoting;
  - creates psmux/Windows panes first, then sends the worker command with `send-keys -l`, followed by `Enter`.
