## Chase Scope

This card separates two error authorities that must never be conflated. Anthropic, Google Gemini CLI/shared, and OpenAI Completions can report policy or safety stops through different wire fields; JWC needs one stable session/ACP meaning while retaining the original provider evidence. A managed fallback can also fail locally before or between provider attempts; that failure must remain a client/transport fact rather than being relabeled as a provider refusal.

JWC already maps several safety indicators in provider adapters and recognizes refusal-like messages in `agent-session.ts`. It does not have the same-path upstream `fallback-transport.ts` or `provider-safety-stop.ts` owners. The chase therefore begins with an inventory of existing normalization and retry decisions, then chooses one canonical typed boundary rather than layering another string-only classifier.

## Decision Log

1. **Canonical type:** `AssistantMessage.errorKind` carries the narrow `AssistantErrorKind = "provider_safety_stop"` classification; provider display text and HTTP status remain separate diagnostics.
2. **Anthropic mapping:** `refusal`, `sensitive`, and refusal `stop_details` set the typed kind, remain terminal after later stream events, and preserve category/explanation text.
3. **Google mapping:** shared GenAI/Vertex and Gemini CLI classify explicit candidate finish reasons and prompt block reasons through separate allowlists; safety remains sticky and cannot be promoted to `toolUse`.
4. **OpenAI mapping:** `content_filter` finish reasons, streamed `refusal`, and structured HTTP error code `content_filter` are typed; incidental message text is not authoritative.
5. **Fallback authority:** only provider wire fields set `provider_safety_stop`; local endpoint/transport failures retain their existing local/transient classifications.
6. **Retry policy:** typed safety stops are terminal before overflow, compaction, retry, or model fallback. This prevents deterministic replays and repeated billing.
7. **Session compatibility:** the typed field is authoritative for new responses. A separate anchored matcher handles only persisted pre-type labels.
8. **Fixtures:** focused provider and session tests use isolated fetch/model state and assert both positive and negative classification paths.
