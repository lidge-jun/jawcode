## WP6 Resolution — 2026-07-11

**ADAPT the JWC-reachable surface; ACCEPT deliberate deferrals.** telegram-command-parser adds
deterministic reasoning, usage, context, compact, and rich grammars. A foreign bot suffix returns ignored;
malformed recognized commands return usage instead of becoming a user turn. Existing lifecycle and
notification config parsers remain intact.

Config now treats JWC_NOTIFY=off as a per-run hard disable, retaining the legacy alias. No Rust/native
protocol duplication was added because JWC owns the loopback protocol in TypeScript. Saved-cwd resume is
N/A under 10.033's fail-closed policy because remote process execution is disabled. Setup cancellation is
also N/A because setup requires explicit flags before any settings write.

## Scope

Import Telegram operational controls: slash-command frames, bot-mention gating for session commands, per-run notification opt-out, session resume from saved cwd, and clean setup cancellation. Public JWC naming must stay `jwc`, `.jwc`, and `JWC_*` unless an explicit compatibility alias is approved.
