## Chase Scope

This card tracks a searchable command palette, direct action dispatch, asynchronous slash-command cleanup, draft preservation, and composer ownership. Upstream protects user input with generation and ownership checks so closing or completing the palette cannot restore stale state over newer edits.

The double-Escape gesture belongs to the same input-loss boundary. JWC already has Escape draft clearing and a double-Escape safety path, so the palette must integrate with those existing contracts and the user-curated TUI behavior instead of replacing the input model.
