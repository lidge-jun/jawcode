This card tracks model selection across retry fallback, role overrides, profile activation, session admission, RPC persistence, and failure rollback. Upstream makes fallback chains sticky, applies `/model` role changes immediately, serializes prompt admission, and promotes only successful selections to the durable default.

The same cluster also changes model-cache reuse, profile credential recovery, Codex preset reasoning, and the GPT-5.6 prompt cap. JWC already has parts of this surface, so the chase must distinguish existing behavior from missing atomicity and persistence rather than treating the cluster as a greenfield port.
