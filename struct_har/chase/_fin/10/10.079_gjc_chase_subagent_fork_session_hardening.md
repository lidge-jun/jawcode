## Residual Risks

- Fork-context cloning can leak provider/session payloads if stripping is incomplete.
- Seed preservation can preserve too much if compaction/rebase boundaries are wrong.
- Yield hardening can reject legitimate subagent results if placeholder matching is too broad.
- IRC guidance can instruct unavailable coordination tools, causing subagents to stall.
- MCP autoload changes alter startup latency and tool availability; keep them separated from subagent executor changes.
- Removing host-inherited MCPs may surprise users relying on Cursor/Gemini/Opencode configs; provide explicit import guidance if adopted.
