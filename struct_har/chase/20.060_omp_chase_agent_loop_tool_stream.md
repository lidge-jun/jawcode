## Chase Scope

This card follows partial provider streams through the agent loop, tool execution, session retry, and ACP presentation. The core invariant is structural: completed tool calls and results remain paired, incomplete calls never execute, an empty `toolUse` stop cannot masquerade as a successful answer, and a provider failure must stay visible to every consumer.

OMP also gates custom Anthropic eager streaming on the effective endpoint and compatibility provenance, recovers malformed arguments, resolves nested `agent://` output, and preserves terminal failed tool turns. JWC already has substantial pairing, aborted-result, retry, provider, internal-URL, and ACP machinery. The relevant files are actively modified in the current worktree, so this card records fit decisions only and must not be used to overwrite those in-flight changes.

All 33 D10 commits are retained, including the revert sequence. The final disposition must follow the surviving upstream state rather than treating every historical fix as cumulative.
