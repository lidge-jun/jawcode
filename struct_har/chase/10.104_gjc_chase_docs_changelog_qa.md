## Chase Scope

This card treats documentation and QA artifacts as one release contract. SDK application guidance and release prose must describe the public package surface that was actually tested. Changelog entries must be deduplicated and preserve an Unreleased section after failed release attempts. PTY transcripts, CLI replay, dogfood reports, package/GitHub/tag receipts, and defensive-copy reports must be generated by fail-closed harnesses and remain immutable after publication.

JWC has package changelogs, release scripts, dogfood guidance, context-usage code, and `structure/60_release_publishing.md` as the release source of truth. The upstream SDK application guide and named `artifacts/` receipts are absent at the same paths. JWC should adopt the evidence properties and audience coverage, not stale versions, GJC names, or historical 0.10.1 receipts.
