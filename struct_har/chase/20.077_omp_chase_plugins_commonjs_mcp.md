## Chase Scope

This card covers legacy CommonJS/ESM plugin interoperability, sibling `require()` resolution, native-addon wrapping, reload-safe helper state, local Claude plugin isolation, custom-loader stdin preservation, extension timer containment, MCP tool ownership, duplicate MCP execution, and skill autocomplete stale-prefix protection.

JWC already has a legacy Pi compatibility mirror, Claude plugin discovery, runtime MCP metadata, and a stale autocomplete guard. The inspected compatibility mirror rewrites ESM import specifiers but does not own CommonJS `require()` graphs. More importantly, JWC's runtime MCP manager still removes tools with a synthesized name-prefix test even though each MCP tool carries `mcpServerName`; this is a concrete ownership gap, not merely a naming difference.

All 12 matching commits are retained. Cursor transport details remain secondary to the no-duplicate-execution invariant; general session disposal remains with 20.076.

- [ ] Reproduce linked legacy plugin graphs that mix ESM imports, CommonJS siblings, and native addons.
- [ ] Prove reloads replace helper/module state instead of retaining stale exports.
- [ ] Replace MCP server tool removal by synthesized prefix with explicit `mcpServerName` ownership where safe.
- [ ] Preserve stdin listener/pause state across custom tool, hook, extension, and plugin imports.
- [ ] Contain extension-scheduled callback failures and clear managed callbacks at shutdown.
- [ ] Retain the slash/skill stale-prefix guard when autocomplete state changes asynchronously.
