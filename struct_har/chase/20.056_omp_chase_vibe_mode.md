## Chase Scope

OMP's vibe runtime keeps worker sessions alive across spawn, send, wait, list, and kill operations. The interactive UI mirrors shared state, while runtime tests cover identity, concurrency, and cleanup. This is more than asynchronous task execution: the worker remains addressable after a turn.

The supplemented range also contains tangential-agent isolation, `btw` Codex WebSocket state, downshift/plan-yolo/reasoning-slide experiments, guided-goal side sessions, transcript-collapse settings, and the later removal of boomerang behavior. These commits must be read as an experiment history, not a single feature to copy at its largest midpoint.

## Worktree Verification

JWC has task execution, async jobs, `jobs-overlay-model.ts`, `modes/background-row-model.ts`, tmux-backed team runtime, and durable goal/workflow state. It has no `src/vibe/` directory or `tools/vibe.ts`, and the targeted sweep found no downshift/boomerang implementation. Therefore persistent addressable workers are a product decision with overlap risk, while the downshift series is historical design evidence whose terminal state includes explicit removal.
