## Why This Sub-Card

This slice spans provider stream accounting, compaction retry classification, JSON/session persistence, legacy stats ingestion, provider catalog policy, task naming and orchestration, debugger fallback, and system-prompt guidance. Its runtime seam is lossless state at external and historical boundaries, while its policy seam is intentionally JWC-owned: provider support, role names, prompt topology, and debugger behavior cannot be inherited merely because OMP changed them.

JWC owner signals are `packages/ai/src/providers/`, `packages/agent/src/compaction/`, `packages/utils/src/json.ts`, `packages/stats/src/db.ts`, `packages/coding-agent/src/session/{agent-session,session-manager}.ts`, `packages/coding-agent/src/task/`, `packages/coding-agent/src/prompts/`, `packages/coding-agent/src/dap/`, and `packages/coding-agent/src/tools/debug.ts`. The current tree keeps provider descriptors under `packages/ai/src/provider-models/`; Novita, Delve, and OMP's advisor/tester topology are not assumed to exist.

## Reference Decisions

| commit group | decision | rationale |
| --- | --- | --- |
| Compaction retry (`cdecf65f8`) | **reference/adapt** | Credential failures are retry-classification facts, but JWC's model selection and auth fallback paths differ. Map the error predicate into JWC's compaction owner only if retry remains bounded and cannot mask permanent auth failure. |
| OpenAI terminal usage (`8495931e0`, `f9ead2ac4`) | **adapt** | Zero-valued placeholders and final cached-token deltas are lossless stream-accounting invariants. Verify merge ordering at terminal close against JWC's current usage accumulator. |
| Bigint JSON and legacy stats (`531880c62`, `7df2ac297`) | **adapt** | Serialization and historical-row tolerance are portable correctness properties. Reuse JWC's shared JSON helper and stats normalization boundaries rather than scattering coercions. |
| Task/prompt policy (`1b490044f`) | **reference/reject-by-default** | JWC already owns a substantial native orchestration surface. Compare policy centralization and invalidation intent, but do not import OMP's prompt topology into JWC's PABCD/task contracts. |
| Novita provider (`a45ecd559`, `f79098b9b`, `68c3c7ea9`) | **reference** | Add only through an explicit JWC provider-support decision; descriptor, discovery/login behavior, generated catalog output, tests, environment docs, and user docs form one review unit. |
| Explore-to-scout rename (`6dbbfbe1e`) | **reject-by-default** | JWC currently uses `explore` as a callable role and in spawn gates/prompts. A rename is product vocabulary and compatibility work, not a portable upstream fix. |
| Missing Delve (`e8add6101`) | **reference/adapt** | If JWC exposes the equivalent Go DAP route, a missing adapter should fail explicitly rather than enter an invalid native fallback. No literal Delve route was found in the targeted sweep. |
| Advisor/testing prompts (`60c9ad625`, `e2e5d8835`) | **reference/reject-by-default** | Guidance placement is JWC system-prompt and role-policy ownership. Compare behavioral intent, but preserve JWC's existing role set, prompt composition, and workflow gates unless separately approved. |
