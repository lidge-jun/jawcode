## Chase Scope

This cluster moves small-model preprocessing and guidance toward one owner, preserves the chat envelope during title generation, formalizes task-agent frontmatter/model/thinking precedence, and simplifies OMP's delegation prompt and agent inventory.

JWC already has a strong role model: `executor`, `executor_ext`, `architect`, `planner`, and `critic` have documented responsibilities, and model resolution is coupled to authenticated fallback rules. OMP's removal of its plan subagent and flat task structure is therefore a negative reference, not a direct migration. The useful candidates are centralized title/small-model shaping, envelope preservation, frontmatter parsing, and precedence tests.

- [ ] Identify one JWC preprocessing entry point for small title/helper models.
- [ ] Preserve role/chat envelopes before text reduction or title generation.
- [ ] Lock model and thinking precedence across agent frontmatter, caller override, and authenticated fallback.
- [ ] Keep `planner`, `architect`, and `critic`; reject inventory changes that break the JWC workflow contract.
- [ ] Compare prompt guidance semantically without replacing JWC identity, workflow, or plan-mode text wholesale.
