## Why This Is A Gap

OMP v16.2.5→v16.2.9 reworked web-search backends and provider selection: DuckDuckGo search now scrapes the HTML frontend instead of the Instant Answer API (with native-browser-aligned requests), the `--provider auto` override is honored, search provider settings are applied from config, gemini api-key search is supported (reusing the gemini oauth helper), and the DuckDuckGo result cap was intentionally kept unchanged. JWC's web-search surface (hardened in 10.043 _fin) can reference the DDG-scrape migration and provider-settings plumbing.

Behavioral surface:
1. DuckDuckGo: scrape HTML frontend instead of Instant Answer API; align requests with native browser behavior.
2. Honor explicit `--provider auto` override; apply search provider settings from config.
3. Support gemini api-key search (reuse gemini oauth helper).
4. DuckDuckGo result cap intentionally unchanged (`keep` commit — documented non-change).
