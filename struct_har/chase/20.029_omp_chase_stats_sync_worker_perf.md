## Why This Is A Gap

OMP v16.2.5→v16.2.9 hardened its session-stats sync worker and added a perf index: the worker pool is kept for one-file syncs, the native JSONL parser trap is avoided, a macOS stats sync-worker abort is avoided, the sync worker smoke test is skipped on darwin, and a composite index on tool-call timestamp+name was added for session-stats. This is a low-priority infra/perf reference; JWC adopts only if it ships a comparable stats subsystem.

Behavioral surface:
1. Keep worker pool for one-file syncs (avoid teardown cost).
2. Avoid native JSONL parser trap; avoid macOS stats sync-worker abort.
3. Skip sync-worker smoke on darwin (test-env robustness).
4. Composite index on tool-call timestamp + name (perf).
