## Chase Scope

This card tracks coordinator-owned session shutdown, idle reaping, tmux owner-server probing, bounded stdio concurrency, runtime-readiness gating, and fail-closed ACP deletion. The upstream contract ties destructive cleanup to owner proof, exposes an explicit `stop_session`, and distinguishes a missing tmux server from transient probe failures.

JWC already has a coordinator mutation policy, durable turn/session state, tmux delivery checks, and session artifact deletion. The remaining chase is an adaptation rather than a direct copy: cleanup must preserve `.jwc` paths, JWC session identifiers, current turn terminalization, and the existing allow-mutation boundary.
