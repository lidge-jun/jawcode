## Chase Scope

This card covers asynchronous authority at session boundaries: lifecycle subscribers, worker-integration settlement, deferred `agent_end`, queued message epochs, managed session-directory identity, resumable job descriptors, interrupted subagent await, one-session tools-only MCP configuration, resumed retry settlement, Python admission shutdown, prompt/model admission serialization, and stale SDK WebSocket callbacks.

The common failure mode is a completion signal that is valid in isolation but belongs to an older turn, descriptor, connection, or session. JWC has the corresponding job manager, session, MCP, SDK, and Python surfaces, many of them modified in the current worktree. This card must preserve those parallel changes and use focused diffs and tests before proposing any port.
