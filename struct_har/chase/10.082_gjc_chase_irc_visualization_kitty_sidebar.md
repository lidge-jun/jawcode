**Priority rationale:** P1 because stale IRC rows and split-clock expiry races can misrepresent live peer state, while image rendering expands the regression surface into shared TUI capability code.

## Implementation Pressure

Persistent IRC is useful only if the UI and agent observe the same authoritative state. A sidebar row that survives too long, disappears too early, or belongs to an old roster epoch creates false coordination evidence. The timer fixes are therefore correctness work, not cosmetic polish.

Kitty rendering must remain bounded by the visible split. Terminal image protocols can paint outside normal text layout, so clipping, cleanup, resize, and unsupported-terminal fallback need focused tests before this feature is promoted.

## Risk Notes

Do not confuse JWC's HTML export sidebar with the proposed terminal IRC sidebar. They have different owners and lifecycle rules.

Do not import generated docs indexes or upstream naming verbatim. Any public command, setting, state directory, package namespace, or generated label must use `jwc`, `.jwc`, or `@jawcode-dev`.

Use one captured `now` value for projection and timer arming. Fake-clock tests must cover a deadline crossed between phases, stale epoch replacement, sidebar rebuild, resize, and image cleanup.
