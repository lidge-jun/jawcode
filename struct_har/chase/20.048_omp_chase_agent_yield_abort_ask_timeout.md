## Why This Card Exists

OMP changed the ordering boundaries between terminal yields, aborts, task budgets, interactive asks,
stream watchdogs, and extension steering. These are reference invariants, not a request to copy OMP's
session machine. In JWC, equivalent ownership is split across
`packages/coding-agent/src/session/agent-session.ts`, `packages/coding-agent/src/task/executor.ts`,
`packages/coding-agent/src/tools/ask.ts`, `packages/coding-agent/src/modes/controllers/extension-ui-controller.ts`,
`packages/agent/src/agent-loop.ts`, and provider/idle handling under `packages/ai/src/`.

The central question is whether JWC commits user-visible progress before aborting, preserves the source
of an abort, and distinguishes genuine stream idleness from local tool execution or bounded keepalives.
